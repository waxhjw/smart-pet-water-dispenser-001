# 已知限制与证据边界

状态截至 2026-10-16。公开版是开发学习快照，保留 007 固件行为，并非客户生产版本或验收证明。

## 已有记录

- 原开发记录中，目标构建和主机回归通过。
- 用户曾实测 Type-C 带泵出水、电池升压约 5 V 并带泵出水、触摸、雷达、蜂鸣器、绿灯和混色白灯。
- 这些是开发期间的用户反馈，不等于本次公开整理重新完成硬件回归。公开版自身构建和测试结果另列于 `publication-validation.md`。

## 必须继续验证

1. **水位阈值：** 585/420/625 mV 是样机候选参数。线圈偏移、水量、泵差异、采样阻值、放大器、供电和装配都可能影响读数。电流估算不能直接等同于水位。
2. **板卡版本：** 公开硬件原始导出为 2026-09-23；后续调试资料曾引用 2026-10-13 的采样电路。未确认它们与当前样机和 007 源码一一对应，不能直接下单生产。
3. **供电切换异常：** 用户在一块曾被溅水的板上观察到，低水位测试中拔掉 Type-C 后电池持续供电并持续出水。用户怀疑该板损坏，尚无正常板的对照测试。此记录不能写成“硬件故障已确定”或“固件问题已修复”。
4. **指示颜色：** 原始驱动命名为 PB3 红、PA5 绿、PA1 蓝；交接记录中的实物映射为 PA1 红、PA5 绿、PB3 蓝。公开版保持源码原样；红蓝映射及单色报警需重新确认。不能把白灯混色正常当作单红报警已通过。
5. **电池安全与续航：** 约 3.4 V 提示、3.2 V 关机、边充边用、充电满状态、传感器异常、热稳定性、长时运行和实际续航尚未形成完整验收记录。NTC 采样并不等于完整温度保护已验收。
6. **复位与自启动：** 初始化先关泵，但 007 识别 Type-C 后会自动进入连续出水。不能笼统宣称“复位后永远不自动开泵”。异常复位后的端到端行为必须单独实测。
7. **历史专项模式：** PumpTest/BatteryPumpTest 存在强制持续开泵路径，包含对一般关泵函数的特殊处理。它们是历史诊断代码，只供审阅，不作为正常设备固件推荐。
8. **无线异物检测：** 没有独立 FOD（Foreign Object Detection，异物检测）协议证据，不能宣称已经具备该功能。
9. **开发入口：** Windows 目标构建经过公开版检查；其他系统的目标 Makefile 需要适配。VS Code 历史模板需要本地安装 shnote、pyOCD、芯片包等，全部任务并未逐项验收。

发现问题时先核对需求、源码、构建参数、文件指纹、烧录文件、接口与时序，再检查接线、供电和硬件。提 issue 时不要上传客户信息、供应商私有资料或账号凭据。
